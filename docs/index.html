Documentation

Using toast-queue

Get started in a few lines, then customize the queue to fit your app. For the complete API, including options, per-toast configuration, and methods, see the API reference.

Install

Install toast-queue from npm.

npm install toast-queue Copy code

Quick start

Create a ToastQueue instance.

import ToastQueue from 'toast-queue'; const toastQueue = new ToastQueue(); Copy code

Add a toast whenever you need one.

toastQueue.add('Toast message...'); toastQueue.add({ title: 'Changes saved', description: 'Your profile has been updated.', }); toastQueue.add( { title: 'Update available', description: 'A new version is ready to install.', }, { action: { label: 'Reload', onClick: () => location.reload(), }, }, ); Copy code

Styling

toast-queue ships unstyled by default, so you own the presentation. The core stylesheet provides the structural styles needed by the queue, while optional presets add ready-made layout and transition treatments.

/* Core */ import "toast-queue/toast-queue.css"; /* Customization */ toast-queue { /* ... */ [data-part="group"] { /* ... */ } [data-part="item"] { /* ... */ } [data-part="toast"] { /* ... */ } [data-part="icon"] { /* ... */ } [data-part="actions"] { /* ... */ } [data-part="action-button"] { /* ... */ } [data-part="close-button"] { /* ... */ } } Copy code

Presets

  • list: a conventional vertical toast queue where each toast occupies its own space.
  • stacked: a compact card stack where queued toasts overlap behind the active toast.

Both are plain CSS layered under @layer toast-queue, so your own styles win by default. Treat them as a starting point, not a lock-in.

/* list */ import "toast-queue/presets/list.css"; /* stacked */ import "toast-queue/presets/stacked.css"; Copy code

Positioning

Use the logical offset variables to control the inset from the viewport. Set --tq-offset for a uniform inset, or customize the inline and block axes independently.

toast-queue { --tq-offset: 1rem; --tq-offset-inline: var(--tq-offset); --tq-offset-block: var(--tq-offset); } Copy code

Configuration

Queue options

Configuration passed to the ToastQueue constructor.

new ToastQueue({ root: document.body, // Container element for the toast queue duration: 6000, // Auto-dismiss duration in ms (0 disables it) position: 'top-end', // 'top-start' | 'top-center' | 'top-end' | 'center' | 'bottom-start' | 'bottom-center' | 'bottom-end' visibleLimit: 3, // Toasts rendered before the rest are flagged hidden template: null, // Override the default markup }); Copy code

Toast options

Per-toast options are passed as the second argument to .add().

toastQueue.add('Toast content', { duration: 6000, // Auto-dismiss duration in milliseconds. `0` disables automatic dismissal dismissible: true, // Whether the toast can be manually dismissed priority: 'normal', // Announcement priority passed to `ariaNotify()` className: null, // Additional CSS class names applied to the toast icon: null, // HTML markup rendered in the toast's icon slot action: null, // Optional action button configuration onClose: null, // Called after the toast has been closed and removed from the queue }); Copy code

Browser support

toast-queue uses modern, progressively-enhanced browser features, Popover API, View Transitions API, and ariaNotify(), and falls back gracefully where a browser doesn't yet support them (toasts still render and function without animation, just without a transition).

ariaNotify() provides the screen-reader announcement for newly created toasts. Browsers without native support can use a polyfill. Install the polyfill and load it conditionally so browsers with native support skip it entirely.

npm install @github/arianotify-polyfill Copy code
if (typeof HTMLElement.prototype.ariaNotify !== 'function') { await import('@github/arianotify-polyfill'); } const toastQueue = new ToastQueue(); Copy code
